# Bozze editoriali private

Questa cartella non viene letta dal generatore né inclusa nel pacchetto pubblico. Non c'è una pagina blog vuota in navigazione.

Per un futuro articolo: creare qui un file Markdown con titolo, slug, autore, stato bozza, fonti, esempi autorizzati e data effettiva di revisione. Quando esiste un articolo originale verificato, aggiungere un template e una route statica al generatore, poi testarla. Non pubblicare testi solo per riempire categorie.

Primi temi: quando serve un gestionale; costo dei processi manuali; scelta di un sito per piccole attività; quando automatizzare; come valutare software su misura. Ogni articolo deve rispondere a una domanda concreta, illustrare limiti ed esempi verificabili e avere un solo invito al contatto pertinente.
