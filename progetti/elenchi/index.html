Demo personale / Demo funzionante

Un elenco, senza doppioni

Un piccolo strumento per ripulire un elenco mantenendo l'ordine delle voci.

Prova la demo

HTML · CSS · JavaScript · Set

Il contesto

Un esercizio personale su un'attività ricorrente: confrontare righe di testo. Non nasce da una commessa e non usa dati di clienti.

Il problema

Controllare a mano un elenco per trovare voci identiche richiede attenzione e può lasciare doppioni.

Gli obiettivi

Conservare la prima occorrenza di ogni voce e rendere chiaro cosa viene confrontato.

La soluzione

Le righe vengono ripulite dagli spazi ai bordi, normalizzate in Unicode e confrontate con un insieme di valori già incontrati.

L'interfaccia

Un campo per l'elenco, un esempio pronto, il controllo delle maiuscole e un risultato copiabile con conteggi.

Scelte tecniche

Elaborazione nel browser senza dipendenze. Set evita ricerche ripetute nell'intero elenco; nessun invio a servizi esterni.

Difficoltà e limiti

Non riconosce sinonimi, errori di battitura o persone con nomi simili. Limite di 500 righe e 20.000 caratteri.

Risultati osservabili

Nell'esempio incluso, cinque righe diventano tre voci uniche. Il comportamento è ripetibile nella demo; non è una misura di produttività aziendale.
